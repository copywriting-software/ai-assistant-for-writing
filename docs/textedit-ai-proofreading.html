Clean drafts without leaving TextEdit

TextEdit supports direct Accessibility reads and writes. Both full-line Tab completions and selection-based rewrites apply cleanly at the cursor.

cargo run -- rewrite "Draft paragraph here" --style clear

Long document caching

Even when a TextEdit document grows beyond 600 characters, PrefixCache matches shifted suffix windows so typing along a suggestion does not trigger extra model calls.
