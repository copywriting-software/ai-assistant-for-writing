Enforced across every code path

PrivacyGuard runs inside complete_with_context, fix_grammar, rewrite, record_accept, and record_dismiss. Blocked contexts never reach the AI provider and never write to MemoryStore.

cargo test privacy::tests

Customizing blocked apps

Edit the blocked_apps list under [privacy] in config.local.toml to add internal tools or custom terminal emulators.
