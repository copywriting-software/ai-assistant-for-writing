Single source of truth in SessionManager

Instead of showing a thinking spinner in Swift on every keystroke, SessionManager emits ShowThinking only after the adaptive debounce expires and an actual model call begins.

Cancelling obsolete HTTP calls

Every new text_changed snapshot increments the session revision, cancels the previous CancellationToken, and aborts any in-flight reqwest future immediately.
