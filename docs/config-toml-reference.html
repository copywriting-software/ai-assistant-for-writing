Behavior and privacy keys

Control debounce_ms, max_completion_tokens, max_context_chars, cache_size, and blocked_apps in TOML. Environment variables like COREBOX_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY, OLLAMA_URL, AI_WRITING_MODEL, and AI_WRITING_PROVIDER override file values.

cp config.example.toml config.local.toml
cargo run -- check

Checking active configuration

Run cargo run -- check to print the resolved provider kind, base URL, autocomplete model, edit model, and macOS helper status.
