App-specific phrasing memory

MemoryStore tracks accepted completions separately for each application. Greetings and sign-offs you accept repeatedly in Mail are served locally in 0 ms via fast-path matching.

In-place proofreading and concise rewrite

Select a draft paragraph and press Cmd + Shift + G to fix spelling and punctuation, or Cmd + Shift + R to make it shorter while keeping dates, names, and numbers intact.
