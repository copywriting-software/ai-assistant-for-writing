When local models win

For short inline completions, chat replies, and layout fixes, a local 1.5B model keeps every keystroke on your machine with no per-token billing.

ollama pull qwen2.5:1.5b

Hybrid model configuration

You can assign a fast model to autocomplete_model and a stronger model to edit_model in config.local.toml, switching providers in seconds.
