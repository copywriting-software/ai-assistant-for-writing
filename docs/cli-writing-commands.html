CLI commands reference

Test completions, fix grammar, convert layouts, inspect stats, or run the stdio daemon from the command line.

Get on GitHub All 30 guides
Reference
complete <text> Print inline completion suffix
fix <text> Fix grammar and wrong layout
rewrite <text> Rewrite with --style flag
stats / check Inspect memory stats and provider health

Global flags

Pass --config <path> to load a custom TOML file, or --mock to run any subcommand offline with the built-in MockProvider.

cargo run -- --mock complete "Hello, wanted to"
cargo run -- --mock stats

Daemon modes

Run cargo run --release -- daemon to launch the macOS native helper, or add --stdio to speak newline-delimited JSON-RPC over stdin and stdout.
