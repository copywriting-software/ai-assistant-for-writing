AI Assistant for Writing for macOS

Most writing tools lock suggestions inside a single web editor or browser extension. This project runs as a background Rust daemon paired with a lightweight macOS Accessibility helper, so inline autocomplete, grammar fixes, and text rewriting work inside Notes, Mail, Slack, Telegram, Chrome, and TextEdit.

View on GitHub Run offline with Ollama

What the assistant does

System-wide ghost text

Shows a floating completion next to your cursor. Accept the full line with Tab, one word with Option + Right, or dismiss with Esc.

Grammar and layout repair

Press Cmd + Shift + G to fix spelling, punctuation, or text typed on the wrong EN/RU keyboard layout.

Concise rewrite hotkey

Press Cmd + Shift + R to shorten or clarify a selected paragraph in place without switching windows.

Local-first or BYOK API

Works offline with local Ollama models like qwen2.5:1.5b, or connects to OpenAI-compatible, Gemini, and Corebox endpoints.

Quick start on macOS

You need Rust, Xcode command-line tools (swiftc), and Accessibility plus Input Monitoring permissions for the terminal running the daemon.

git clone https://github.com/copywriting-software/ai-assistant-for-writing.git
cd ai-assistant-for-writing

cargo test
./macos/build.sh

# Option A: local free model via Ollama
ollama pull qwen2.5:1.5b
cargo run -- check

# Option B: cloud provider via API key
export OPENAI_API_KEY="sk-..."
cargo run -- check

# Start the background writing daemon
cargo run --release -- daemon

Cmd + Shift + RRewrite selected text in concise style

Privacy rules built into the core

Every request passes through PrivacyGuard before any prompt leaves your machine or touches local memory. The assistant skips password fields (AXSecureTextField), password managers (1Password, Bitwarden, KeePassXC, Keychain Access), terminal emulators (Terminal, iTerm2, Warp, Alacritty, Kitty), and text matching API key prefixes or 16-digit card numbers.
