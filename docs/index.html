Quick start and privacy rules

Grant Accessibility and Input Monitoring permissions to your terminal, then build and start the daemon.

git clone https://github.com/copywriting-software/ai-assistant-for-writing.git
cd ai-assistant-for-writing
cargo test
./macos/build.sh
ollama pull qwen2.5:1.5b
cargo run --release -- daemon
Blocked by PrivacyGuard
Fields AXSecureTextField
Password managers 1Password, Bitwarden, KeePassXC, Keychain
Terminals Terminal, iTerm2, Warp, Alacritty, Kitty
Patterns API key prefixes and 16-digit card numbers
