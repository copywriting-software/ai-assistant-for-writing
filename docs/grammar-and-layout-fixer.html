Grammar, rewrite, and keyboard layout fixer

Typing a full sentence on the wrong keyboard layout or sending a rushed message with typos happens often when switching between languages. Two global shortcuts handle cleanup in place without leaving the active window.

Instant EN/RU keyboard layout repair

The encoding.rs module detects when ASCII characters form Russian words typed on a QWERTY layout (for example, ghbdtn rfr ltkf) and converts them deterministically to Cyrillic (привет как дела) before sending the text to the proofreading prompt. That way, the model sees readable words and can add punctuation and capitalization accurately.

You can also convert text locally from the command line without calling any AI model:

cargo run -- layout "Ghbdtn? rfr ltkf&"
# Output: Привет, как дела?

cargo run -- layout "руддщ цщкдв"
# Output: hello world

One-hotkey proofreading (Cmd + Shift + G)

Select a sentence or paragraph and press Cmd + Shift + G. If nothing is selected, the assistant uses the text before the cursor. The edit request runs asynchronously in the Rust daemon, so you can press Esc to cancel if you change your mind while the model is working.

Rewrite selected text (Cmd + Shift + R)

Select text and press Cmd + Shift + R to rewrite it concisely while keeping facts, numbers, and names intact. From the CLI, four rewrite styles are available: concise, professional, friendly, and clear.

cargo run -- rewrite "Need to call tomorrow to discuss all project details" --style professional
