Deterministic EN/RU layout repair

encoding.rs detects ASCII text typed on an English QWERTY layout as Russian and converts it before sending it to the proofreading prompt.

Cmd + Shift + G

Fixes spelling, punctuation, and broken keyboard layout on the selected text or the text before the cursor. Press Esc to cancel while in flight.

Cmd + Shift + R

Rewrites selected text concisely while preserving numbers, names, and facts. CLI supports concise, professional, friendly, and clear.
