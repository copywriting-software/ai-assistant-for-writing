Adaptive debounce and sliding-window cache

Boundaries trigger faster while mid-word pauses wait for the full configured delay.

Adaptive debounce

At spaces and punctuation, adaptive_debounce_ms shortens wait time to 70% of debounce_ms (80 ms floor). Mid-word typing keeps the full delay.

Sliding-window PrefixCache

When text exceeds max_context_chars (600 chars), PrefixCache matches shifted suffix windows so typed continuations still resolve locally.

Local phrase memory

MemoryStore writes accepted completions and latency metrics to local JSON after PrivacyGuard approves the context.
