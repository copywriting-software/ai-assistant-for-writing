Quick setup with GEMINI_API_KEY

Export GEMINI_API_KEY and run cargo run -- check to verify connectivity before starting the daemon.

export GEMINI_API_KEY="AIza..."
cargo run -- check

Separate autocomplete and edit models

In config.local.toml, you can keep a low-latency model on autocomplete_model while assigning a larger model to edit_model for Cmd + Shift + G and Cmd + Shift + R.
