Verifying the helper and provider

Run cargo run -- check first. It confirms whether the provider endpoint responds and prints the path to the compiled ai-writing-macos-helper binary.

./macos/build.sh && cargo run -- check

Resetting TCC permissions

If you rebuilt without a Keychain signing certificate, remove and re-add your terminal or AIWritingHelper.app under Privacy & Security in System Settings.
