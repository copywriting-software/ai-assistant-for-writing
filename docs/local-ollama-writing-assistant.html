Private local-first AI writing with Ollama

Targets localhost:11434 with qwen2.5:1.5b by default, keeping drafts off external servers.

Get on GitHub Grammar & layout 
ollama pull qwen2.5:1.5b
cargo run -- check
cargo run --release -- daemon

Test from the terminal

Run completions, grammar fixes, and style rewrites directly before enabling the background daemon.

cargo run -- complete "Hi, wanted to follow up on"
cargo run -- fix "ghbdtn rfr ltkf"
cargo run -- rewrite "We need to hop on a call tomorrow to go over every detail." --style concise

Switching to OpenAI, Gemini, or mock mode

Copy config.example.toml to config.local.toml or set an API key environment variable.

Cloud BYOK models

Set OPENAI_API_KEY, GEMINI_API_KEY, or COREBOX_API_KEY. Configure autocomplete_model and edit_model independently.

Offline --mock mode

Pass --mock to test Accessibility permissions, hotkeys, and JSON-RPC output with zero model server running.
