Private local-first AI writing with Ollama

Sending every draft message or internal note to a third-party cloud API is unnecessary for short completions and grammar fixes. By default, ai-assistant-for-writing targets a local Ollama instance on http://localhost:11434 using qwen2.5:1.5b.

Setup in three commands

ollama pull qwen2.5:1.5b
cargo run -- check
cargo run --release -- daemon

You can test completions, grammar fixes, or rewrites directly from the terminal before starting the background daemon:

cargo run -- complete "Hi, wanted to follow up on"
cargo run -- fix "ghbdtn rfr ltkf"
cargo run -- rewrite "We need to hop on a call tomorrow to go over every single detail." --style concise

Switching to OpenAI, Gemini, or Corebox

If you prefer a cloud model for heavier rewriting, copy config.example.toml to config.local.toml or set environment variables (OPENAI_API_KEY, GEMINI_API_KEY, COREBOX_API_KEY). You can also set separate models for fast inline autocomplete and editing via autocomplete_model and edit_model.

Testing without any model server

Pass --mock to any CLI subcommand or daemon invocation to run with the deterministic offline mock provider. This is useful for verifying Accessibility permissions, shortcuts, and JSON-RPC behavior without waiting on a model.

cargo run -- --mock daemon --stdio
