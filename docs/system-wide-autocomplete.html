System-wide ghost text autocomplete on macOS

Code editors have had inline ghost text for years, while email clients, messengers, and note apps still rely on basic OS spellcheck. This tool brings inline completions to standard macOS text fields using the system Accessibility API and a non-activating floating panel.

How cursor context is captured

When you type in a supported app, MacHelper.swift waits 15 milliseconds for the target app to commit the character, then reads the focused element via AXUIElement. Instead of sending an entire document over IPC, it trims the payload in Swift to the last 1,000 characters before the cursor and up to 200 characters after the cursor, along with the active window title.

Navigation keys such as arrow keys, Home, End, PageUp, PageDown, Tab, and Esc are filtered out at the CGEventTap level so moving around a document does not trigger wasted reads.

Context-aware completions (FIM)

The Rust engine builds a short prompt containing three signals when available:

  • Text before the cursor, trimmed to max_context_chars (600 by default).
  • Text after the cursor, so the model avoids repeating words you already wrote.
  • Active application name and window title, helping match tone between a chat message and a formal email.

Safe insertion without overwriting newer typing

Before inserting accepted text, the macOS helper checks that the text right before the cursor still matches the prefix used to generate the suggestion. If you kept typing while a request was in flight, the stale insertion is aborted rather than corrupting your sentence.

In native AppKit apps (Notes, TextEdit, Mail), text is inserted directly through kAXSelectedTextAttribute. In Electron and Chromium apps (Slack, Chrome, Telegram), the helper falls back to a clipboard paste and restores your previous clipboard contents after 150 milliseconds.

Partial acceptance and dismissal

If only the start of a suggestion fits what you want to say, press Option + Right to accept one grapheme-aware word at a time. Pressing Esc cancels any in-flight HTTP request and pauses autocomplete until you type a space or start a new word.
