How cursor context is captured

MacHelper.swift reads the focused element through AXUIElement and filters out navigation keys at the CGEventTap level.

Filtered keys (no AX read)

Arrow keys, Home, End, PageUp, PageDown, Tab, and Esc never trigger snapshot reads or reset timers.

Three prompt signals

Text before cursor (600 chars), text after cursor (200 chars) so the model does not repeat existing words, and window title for tone.

Safe insertion and partial accept

Before inserting text, the helper verifies that the prefix before the cursor still matches the request.

Native vs Electron

Notes, TextEdit, and Mail insert directly via kAXSelectedTextAttribute. Slack, Chrome, and Telegram paste via clipboard and restore it after 150 ms.

Word-by-word and Esc

Press Option + Right to accept one grapheme-aware word at a time. Press Esc to cancel in-flight requests and pause until the next space.
