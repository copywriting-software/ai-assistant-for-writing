Reference
Transport Newline-delimited JSON (stdin/stdout)
Start command ai-assistant-for-writing daemon --stdio
Events in text_changed, accept_all, accept_word, dismiss, fix_grammar, rewrite
Commands out show_thinking, show_ghost, hide_ghost, insert_text, replace_selection

Input event format

Send a JSON object with an event tag and FocusSnapshot fields. Optional fields like window_title and text_after_cursor default to null when omitted.

{"event":"text_changed","app_name":"Notes","is_secure_field":false,"text_before_cursor":"Hello, wanted to"}

Output command sequence

The daemon emits hide_ghost immediately to clear stale state, show_thinking once the adaptive debounce finishes, and show_ghost when the provider responds.
