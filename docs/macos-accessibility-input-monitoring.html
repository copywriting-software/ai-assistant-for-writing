Accessibility and Input Monitoring on macOS

Configure macOS privacy permissions once and sign the helper so rebuilds keep your settings.

Why signing matters for TCC

macos/build.sh checks your Keychain for a code-signing identity and signs AIWritingHelper.app with a stable bundle identifier. That prevents macOS from invalidating Accessibility permissions after every rebuild.

./macos/build.sh
cargo run -- check

Menu bar status indicator

When the daemon starts, the helper adds a menu bar item showing whether Accessibility is active and provides a shortcut straight to System Settings if permission is missing.
